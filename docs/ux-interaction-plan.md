# Nanako 桌面互動體驗規劃

> 狀態：第一版桌面多視窗模型已實作；檔案管理器導覽深度與剩餘功能仍持續完善。介面用語採繁體中文（台灣）。

## 產品模型

Nanako 是在單一 Electron 視窗內模擬桌面作業系統的本機檔案服務，不是把所有功能堆在一張管理頁面，也不接管 Windows 桌面。使用者從 Nanako 桌面啟動應用程式，在桌面內的個別視窗完成工作；視窗、導覽列與圖示只能呈現 Nanako 自己管理的功能及資料。

### 不可違反的產品邊界

- 檔案、相簿、播放器、資源回收桶、ZIP、重複檔案整理與加密空間都只能存取可攜式執行檔旁的 `NanakoData`。
- 不列出或導覽 C:、其他磁碟、Windows 已知資料夾或任意外部資料夾；不把來源路徑掛載成 Nanako 空間。
- 「匯入檔案」是一次性複製動作，不是開啟來源目錄；匯入完成後，Nanako 只管理自己的副本。
- 桌面視覺可仿作業系統的工作列、捷徑、應用程式選單與內部視窗，但關閉 Nanako 內部視窗不會停止本機服務或關閉 Windows。
- 本機帳號與權限為主，不依賴雲端帳號或 SSO。SMB 是必要功能規劃，不是可有可無的外掛；啟用及權限操作只由明確授權的管理員控制。

## 觀察到的互動模型

Nanako 的操作層級為「桌面 → 應用程式視窗 → 應用程式工作區」。桌面負責啟動與切換應用程式；各視窗管理自己的工作狀態；工作區只呈現該應用程式的功能。檔案管理與重複檔案整理是不同的視窗，前者管理 Nanako 內的檔案，後者唯讀比對並在確認後整理副本。

Nanako 不在「我的電腦」列出 Windows 磁碟代號，也不提供任選外部資料夾的去重流程。桌面只呈現 Nanako 自身應用程式捷徑；儲存空間畫面只顯示 `NanakoData` 用量；去重功能固定掃描 Nanako 管理範圍。

## 目前原型與目標的差距

目前已有桌面背景、捷徑、應用程式選單、頂端工作列與 Dock。應用程式現在使用獨立的 Nanako 內部視窗，可同時開啟、切換前景、拖曳／方向鍵移動、最小化、最大化／還原、關閉及從工作列還原；同一應用程式採單一視窗，再次啟動會聚焦既有視窗。關閉視窗不會關閉本機服務或 Windows。主要視窗生命週期操作會寫入操作紀錄。後續重點是強化檔案管理器的 Nanako 虛擬位置導覽，以及完成剩餘情境操作，不改變權限與 `NanakoData` 範圍限制。

## 目標資訊架構

### Nanako 桌面

- **頂端全域列**：應用程式選單、已開啟應用程式／工作區切換、服務本機狀態、帳號，以及管理員可見的系統設定入口。
- **桌面捷徑**：檔案管理、相簿、播放器、資源回收桶、儲存空間、加密空間及管理員工具。只有已實作或清楚標示規劃中的功能可出現；不製作 Windows 磁碟捷徑。
- **工作列／Dock**：顯示執行中的 Nanako 應用程式及作用中狀態。再次選取已開啟的應用程式會將原視窗帶到前景，不建立重複視窗。
- **登入後入口**：以 Nanako 桌面為起點；首次使用時可顯示本機資料空間導覽，但不自動開啟多個功能視窗。
- **桌面狀態卡片**：在桌面右上方呈現本機時間、目前帳號可用的資料空間數量及服務本機運作狀態，可直接開啟儲存空間；不向外查詢天氣或雲端資料，窄版畫面會收起卡片避免遮住捷徑。
- **啟動器快速列**：完整 App Drawer 上方固定提供檔案管理、相簿與播放器快速入口；其餘功能仍在完整清單中，快速列不取代鍵盤可操作的格狀清單。

### 內部應用程式視窗

- 每個應用程式都有自己的標題、內容與最小化／最大化還原／關閉控制；作用中視窗有清楚的前景層級。
- 拖曳、最大化及還原後保留可預期的視窗位置。關閉只關閉該 Nanako 視窗；最小化保留工作狀態並可從工作列還原。
- 視窗控制有可見焦點、鍵盤替代操作及一致的無障礙名稱；不要求使用者必須拖曳才能操作。
- 若視窗內容正有未完成的上傳、壓縮或其他工作，關閉前說明工作是否會取消；不得靜默丟棄進度。

### 檔案管理器

目前檔案管理視窗已提供「我的檔案」、圖片／影片／音訊／文件分類，以及連至檔案去重與資源回收桶的工具入口。分類會在目前選取的 Nanako 資料空間遞迴搜尋，檔名文字可縮小分類結果；每筆結果會附上 Nanako 相對位置，點選時先導向檔案實際所在資料夾，再交由既有檔案流程開啟。分類檢視不允許選取、批次異動或刪除；一般檔名搜尋仍限於目前資料夾，並支援名稱、修改時間與大小排序。分享資料空間選擇器只列 Nanako 管理的資料空間；分類搜尋最多檢查 100,000 個項目並顯示至多 1,000 筆，超量時提供縮小搜尋的提示。這些操作都不建立外部路徑、Windows 磁碟或個人資料夾入口，也不包含資源回收桶與內部暫存目錄。

後續若新增更多導覽項目，也只能使用 Nanako 內的虛擬位置與功能：

- 我的檔案、公共空間。
- 分類檔案：圖片、影片、音訊、文件。
- 最近上傳、我的分享、我的最愛、標籤。
- 資源回收桶、檔案去重。

工作區提供返回／前進、重新整理、Nanako 相對路徑麵包屑、搜尋、排序、清單／網格切換、匯入檔案、新增資料夾與選取後的情境操作。工具列只顯示目前位置和權限允許的動作；沒有權限時說明原因，不以失效按鈕或隱藏錯誤代替回饋。所有路徑都是 Nanako 內部相對路徑，畫面不顯示或接受磁碟代號及外部絕對路徑。

### 重複檔案整理

> 目前狀態：第一版掃描與可復原整理流程已實作，並可由 Nanako 桌面獨立視窗執行；大型資料量操作及中斷復原驗證仍待完成。

- 從 Nanako 桌面捷徑或應用程式選單開啟獨立視窗；開始畫面直接說明掃描範圍固定為 `NanakoData`，不顯示「任選資料夾」的按鈕。
- 開始掃描前揭露工作內容；掃描唯讀、可取消、顯示進度。依檔案內容比對，不只依名稱或大小判定。
- 結果以重複群組呈現相對路徑、大小、修改時間與可回收容量；使用者必須逐組指定保留項目。
- 整理前預覽將移除的副本，經明確確認後移到 Nanako 資源回收桶；不自動挑選、不直接永久刪除，並記錄每一筆成功／失敗結果。
- 詳細驗收與邊界見 [重複檔案整理規劃](feature-plan-duplicate-files.md)。

### 相簿、播放器、資源回收桶與管理工具

- 相簿與播放器預設呈現目前選取 Nanako 資料空間的全域媒體索引，提供檔名搜尋、清楚顯示相對路徑及 1,000 筆上限提示；使用者也可切換成原有的資料夾逐層瀏覽模式。相簿支援全螢幕檢視，播放器支援播放清單及實際播放測試。媒體點選後在 Nanako 內檢視／播放，不把來源檔交給外部程式開啟。
- 相簿縮圖與播放清單採每批 48 筆漸進呈現；圖片延遲載入，關閉相簿／播放器視窗時釋放圖片索引、播放佇列與媒體來源。新視窗以 160 毫秒位移／淡入提供操作回饋，並遵循 Windows 減少動態效果偏好。
- 檔案管理清單每批呈現 100 列，保留全選目前資料夾、批次操作與排序對完整清單的語意；關閉檔案管理視窗時清除列 DOM，重新開啟再載入目前路徑。
- 資源回收桶清楚分開「還原」與「永久刪除」；永久刪除必須明確確認並受管理員／權限規則保護。
- 「儲存空間」呈現 NanakoData 容量及管理範圍，不等同 Windows「我的電腦」或磁碟瀏覽器。
- 電腦資訊與管理員功能只對管理員顯示；一般使用者不必處理程式提升、安裝服務或 Windows 權限細節。
- 網路／SMB 管理功能日後放在清楚的管理員設定區，顯示實際綁定介面、連接埠與連線狀態；目前不可用的控制不得偽裝成已啟用。

## 一致互動規則

- 主要操作使用明確動詞，例如「匯入檔案」、「移至資源回收桶」、「還原」、「開始掃描」；避免「更多」中藏入高風險操作。
- 載入中、成功、失敗、空狀態、權限不足、取消及部分成功都要在原視窗內有可理解的回饋；長時間工作顯示進度與取消能力。
- 破壞性操作在執行前說明影響範圍與可復原性；取消是預設焦點，不在載入完成後自動觸發動作。
- 滑鼠與鍵盤操作等價：Tab 順序符合畫面順序，焦點清楚，Enter／Space 可啟動按鈕，Esc 可關閉可取消的對話框；不以拖曳作為唯一操作方式。
- 圖示按鈕有可理解的無障礙名稱；狀態不只靠顏色傳達。遵守可讀對比、足夠點擊目標、`prefers-reduced-motion` 與語意化 HTML。
- 搜尋、選取、切換檢視、麵包屑與關閉視窗等常見操作不造成意外清除選取、重新播放或資料異動。

## 推進順序

1. **檔案管理導航**（持續完善）：已有 Nanako 內部側邊導覽、資料空間全域分類搜尋、目前資料夾檔名搜尋與排序；後續再補有實際資料模型支援的 Nanako 虛擬位置，不呈現 Windows 磁碟入口。
2. **檔案情境操作**：統一單筆／批次操作、確認、進度、取消、錯誤復原與操作紀錄。
3. **媒體及回收流程**：驗證相簿、播放器、資源回收桶在獨立視窗下仍維持 Nanako 範圍並可還原。
4. **重複檔案整理**：依專屬規劃完成唯讀掃描、人工選擇保留項、可復原整理與大型檔案測試。
5. **網路與 SMB**：在必要的管理員安裝與權限分離完成後，才將服務狀態與管理操作接入桌面工作流程；未通過協定與跨裝置測試前維持未啟用。

## 設計系統取捨

UI/UX 指引搜尋結果未找到適合 Windows 仿桌面檔案管理器的精確版型，因此不直接套用行銷頁或 SaaS 儀表板模板。視覺延續 Nanako 現有冷色桌面、淺色視窗與清楚藍色主動作；使用簡潔扁平表面及有限陰影來區分桌面、視窗、內容與對話框。這是依現有介面與產品情境制定的 fallback，不是套件或第三方資產採用紀錄。

新增的風格參考採取「桌面辨識度＋本機狀態卡片＋快速啟動」方向：桌面小工具只展示 Nanako 本機時間、資料空間數量與服務狀態；啟動器在完整 App Drawer 上方加入三個常用入口，不採用環形手勢作為主導航，並保留鍵盤操作。細節及平台不採用項目見[介面與產品設計參考](design-references.md)。
