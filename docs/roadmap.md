# 版本規劃

此文件是目前規劃，不代表已承諾的發行日期。每階段需通過對應測試後才能標示完成。

## v0.1 — 本機功能原型（目前）

- [x] Electron 桌面視窗與本機 HTTP UI。
- [x] 在 Nanako 視窗內模擬桌面操作體驗：桌面捷徑、應用程式選單、工作列與內部視窗控制；不接管 Windows Shell。
- [x] 本機管理員／使用者帳號、分享資料夾讀寫權限。
- [x] 檔案瀏覽、建立資料夾、上傳、下載、資源回收桶與還原。
- [x] 僅綁定迴圈介面、無遠端服務呼叫。
- [x] Electron Windows x64 可攜式 `.exe` 建置與封裝後媒體測試模式啟動。
- [ ] 完整桌面介面首次設定、關閉重開與資料保留測試。
- [ ] UI、API 與資料完整性測試擴充。

## v0.2 — 本機媒體與可攜式（目前）

- [x] 相簿資料夾導覽、圖片網格與全螢幕檢視。
- [x] 瀏覽器原生影音播放清單與單一 byte-range 串流。
- [ ] 縮圖快取、轉碼策略、字幕與播放進度。
- [x] 檔案、相簿、播放器與資源回收桶都限制在可攜式執行檔旁的 `NanakoData`；不瀏覽或掛載其他磁碟與資料夾。
- [x] 本機電腦資訊檢視（作業系統、CPU、記憶體、資料磁碟容量、網路介面）。
- [x] Electron／Chromium 媒體能力提示，以及僅針對 Nanako 資料空間內媒體的相容性測試流程。
- [x] Windows x64 可攜式發行檔建置；封裝媒體測試模式可啟動並產生 JSON 報告。
- [ ] 以匯入的真實來源檔驗證媒體矩陣、完整 UI 流程與關閉重開後的資料保留。
- [ ] 可攜式版本升級與復原流程。
- [x] 主要使用者操作紀錄、管理員保留期限設定、自動清除與手動清空防呆確認。
- [x] 管理員修改一般使用者資料空間權限、停用／重新啟用帳號，並於停用時撤銷工作階段。
- [x] 使用者自行變更密碼並撤銷其他工作階段；登入錯誤節流（5 次／15 分鐘）。
- [x] 管理員介面檢視目前 Windows 身分、系統管理員群組與程序是否已提升。
- [ ] 管理員身分安裝流程，以及一般 Windows 帳號使用 Nanako 時的權限分離與操作流程。
- [ ] 檔案操作完整性、錯誤復原、容量與併發處理。
- [x] 一般 Nanako 檔案的 ZIP 串流建立／解壓縮原型與 ZIP Slip 基本測試。
- [ ] ZIP 大檔案記憶體量測、取消／進度、損毀封存測試與 Windows 檔案總管互通性驗證。

## v0.3 — 本機壓縮與加密空間（規劃中）

- [x] ZIP 壓縮與解壓縮僅在 NanakoData 內操作，採串流處理、拒絕路徑跳脫／符號連結，並提供 CRC 檢查與失敗暫存清理原型。
- [ ] 完成 ZIP 相容性、安全與大檔案驗證；zip.js 2.24.0 已採用並記錄至 `THIRD_PARTY.md`。
- [ ] 上鎖檔案以加密資料保存於 NanakoData，使 Windows 檔案總管無法直接讀取其原始內容。
- [ ] 設計並測試金鑰建立、解鎖／鎖定、錯誤密碼、記憶體金鑰清除與備份／復原流程。
- [ ] 加密檔案內容與敏感中繼資料，提供 Nanako 內受控的檢視／播放；不得以明文暫存檔做假解鎖。
- [ ] 完成串流格式、資料損毀偵測、升級相容性與安全測試後，才將功能標示為可用。

## v0.4 — 安全區域網路分享

- 預設關閉，由使用者明確啟用。
- 網卡／IP／連接埠選擇，顯示實際連線狀態。
- TLS、防火牆規則管理、威脅建模與跨裝置測試。
- 任何網路功能均須先通過安全審查，才能標示為可用。

## v0.5 — 整合 API

- 版本化本機 API、可撤銷的 API Token、權限範圍、OpenAPI 與串接範例。
- 依使用者需求再評估可選 SMB；不將 SMB 當成本機檔案操作的前置條件。
