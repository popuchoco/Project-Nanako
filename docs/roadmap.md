# 版本規劃

此文件是目前規劃，不代表已承諾的發行日期。每階段需通過對應測試後才能標示完成。

## v0.1 — 本機功能原型（目前）

- [x] Electron 桌面視窗與本機 HTTP UI。
- [x] 在 Nanako 視窗內模擬桌面操作體驗：桌面捷徑、應用程式選單、工作列與內部視窗控制；不接管 Windows Shell。
- [x] 功能頁改為獨立 Nanako 內部應用程式視窗，支援作用中視窗、工作列／Dock 切換、拖曳／方向鍵移動、最小化、最大化／還原、關閉及重複開啟聚焦；主要視窗操作寫入操作紀錄，不接管 Windows Shell。
- [x] 本機管理員／使用者帳號、分享資料夾讀寫權限。
- [x] 檔案瀏覽、建立資料夾、上傳、下載、重新命名、移動、串流複製、批次操作、資源回收桶與還原。
- [x] 僅綁定迴圈介面、無遠端服務呼叫。
- [x] Electron Windows x64 可攜式 `.exe` 建置與封裝後媒體測試模式啟動。
- [ ] 完整桌面介面首次設定、關閉重開與資料保留測試。
- [ ] UI、API 與資料完整性測試擴充。

## v0.2 — 本機媒體與可攜式（目前）

- [x] 相簿資料夾導覽、圖片網格與全螢幕檢視。
- [x] 瀏覽器原生影音播放清單與單一 byte-range 串流。
- [ ] 縮圖快取、轉碼策略、字幕與播放進度。
- [x] 檔案、相簿、播放器與資源回收桶都限制在可攜式執行檔旁的 `NanakoData`；不瀏覽或掛載其他磁碟與資料夾。
- [x] 本機電腦資訊檢視（作業系統、CPU、記憶體、資料磁碟容量、網路介面）。
- [x] Electron／Chromium 媒體能力提示，以及僅針對 Nanako 資料空間內媒體的相容性測試流程。
- [x] Windows x64 可攜式發行檔建置；封裝媒體測試模式可啟動並產生 JSON 報告。
- [ ] 以匯入的真實來源檔驗證媒體矩陣、完整 UI 流程與關閉重開後的資料保留。
- [ ] 可攜式版本升級與復原流程。
- [x] 主要使用者操作紀錄、管理員保留期限設定、自動清除與手動清空防呆確認。
- [x] 管理員修改一般使用者資料空間權限、停用／重新啟用帳號，並於停用時撤銷工作階段。
- [x] 使用者自行變更密碼並撤銷其他工作階段；登入錯誤節流（5 次／15 分鐘）。
- [x] 管理員介面檢視目前 Windows 身分、系統管理員群組與程序是否已提升。
- [ ] 管理員身分安裝流程，以及一般 Windows 帳號使用 Nanako 時的權限分離與操作流程。
- [x] NanakoData 內重新命名／移動／複製與逐項批次操作；拒絕覆寫、路徑跳脫、符號連結及資料夾自我巢狀操作。
- [x] NanakoData 內重複檔案掃描與可復原整理原型：串流 SHA-256 比對、進度／取消、逐組指定保留項、權限檢查、移至資源回收桶及逐筆操作紀錄；單次上限 100,000 個項目，詳見 [重複檔案整理](feature-plan-duplicate-files.md)。
- [x] 檔案管理器加入 Nanako 內部側邊導覽、所選 Nanako 資料空間的圖片／影片／音訊／文件遞迴分類搜尋（最多掃描 100,000 項、顯示 1,000 筆）、分類檔名搜尋、目前資料夾搜尋與名稱／修改時間／大小排序；分類結果顯示相對位置並停用直接異動。
- [ ] 大型資料夾操作進度／取消、記憶體與效能量測、磁碟空間變動、作業中斷復原及併發競態驗證。
- [x] 一般 Nanako 檔案的 ZIP 串流建立／解壓縮原型與 ZIP Slip 基本測試。
- [ ] ZIP 大檔案記憶體量測、取消／進度、損毀封存測試與 Windows 檔案總管互通性驗證。

## v0.3 — 本機壓縮與加密空間（規劃中）

- [x] ZIP 壓縮與解壓縮僅在 NanakoData 內操作，採串流處理、拒絕路徑跳脫／符號連結，並提供 CRC 檢查與失敗暫存清理原型。
- [ ] 完成 ZIP 相容性、安全與大檔案驗證；zip.js 2.24.0 已採用並記錄至 `THIRD_PARTY.md`。
- [ ] 上鎖檔案以加密資料保存於 NanakoData，使 Windows 檔案總管無法直接讀取其原始內容。
- [ ] 設計並測試金鑰建立、解鎖／鎖定、錯誤密碼、記憶體金鑰清除與備份／復原流程。
- [ ] 加密檔案內容與敏感中繼資料，提供 Nanako 內受控的檢視／播放；不得以明文暫存檔做假解鎖。
- [ ] 完成串流格式、資料損毀偵測、升級相容性與安全測試後，才將功能標示為可用。

## v0.4 — SMB 與安全區域網路分享（必要功能）

- [ ] 完成 Windows 管理員安裝服務／受控代理程式與一般 Windows 帳號操作的權限分離設計。
- [x] 管理員介面唯讀檢視 Windows SMB Server 服務、TCP 445 使用狀態、分享管理命令與 Nanako 程序提升狀態（不修改主機設定）。
- [ ] SMB Server 技術概念驗證：協定安全性、Nanako 帳號認證、逐分享授權與 NanakoData 嚴格隔離。
- [ ] 在 Nanako 視窗內提供 SMB 服務狀態、啟停、分享清單、使用者授權與錯誤紀錄管理介面。
- [ ] 由管理員明確啟用 SMB；預設關閉，停用後確認所有 SMB 監聽器停止。
- [ ] 網卡／IP 選擇必須實際限制 SMB 監聽介面，並顯示實際連線狀態。
- [ ] 驗證 SMB 連接埠與用戶端相容性；管理網頁服務連接埠與 SMB 連接埠分開設定。
- [ ] 完成 Windows 檔案總管、macOS Finder 與 Linux `smbclient` 跨裝置測試、威脅建模與安全審查。
- [ ] 不自動設定路由器連接埠轉送；未通過安全與互通測試前不得標示為可用。

## v0.5 — 整合 API

- 版本化本機 API、可撤銷的 API Token、權限範圍、OpenAPI 與串接範例。
- SMB 是本專案必要功能，依 v0.4 進度持續實作，不列為可選項目。
