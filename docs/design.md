# 介面與互動設計

> 狀態：第一版功能原型。UI 用語採繁體中文（台灣）；細節依實際使用者測試調整。

## 設計原則

1. **先看懂狀態，再執行動作**：清楚呈現目前登入者、所選分享資料夾、所在路徑及讀寫權限。
2. **破壞性操作可復原**：一般刪除先移到資源回收桶；永久刪除需管理員操作並明確確認。
3. **權限不可只靠 UI**：隱藏或停用按鈕只是提示，API 必須重新檢查使用者權限。
4. **本機優先、無雲端依賴**：登入、檔案與設定均在本機處理；不暗中建立遠端帳號或同步。
5. **以台灣慣用語呈現**：所有 UI 訊息、錯誤說明、文件都使用繁體中文（台灣）詞彙。
6. **桌面外觀只在 Nanako 視窗內模擬**：仿桌面工作列、捷徑及應用程式視窗是 Nanako 的介面，不接管 Windows 桌面、不操作 Windows Shell。

## 目前主要畫面

- **Nanako 桌面**：在 Nanako 視窗內提供桌面捷徑、應用程式選單、工作列、時鐘及可拖曳／最小化／最大化／關閉的內部應用程式視窗；關閉內部視窗只回到 Nanako 桌面，不會關閉服務或 Windows。
- **初始設定／登入**：僅建立本機管理員與本機帳號登入。密碼要求至少 12 個字元。
- **檔案管理**：只瀏覽可攜式執行檔旁 `NanakoData` 內的 Nanako 資料空間；支援建立資料夾、匯入（複製）檔案、下載及移至資源回收桶。匯入來源不會成為可瀏覽或管理的資料夾。
- **相簿**：只瀏覽 Nanako 資料空間中的圖片，支援資料夾導覽與全螢幕圖片檢視；目前直接由瀏覽器載入原圖，尚未產生縮圖。
- **播放器**：只列出 Nanako 資料空間中的影音檔，提供音訊／影片播放清單與瀏覽器原生控制項；格式解碼能力依 Electron 內建 Chromium 而異。
- **資源回收桶**：只檢視及還原 Nanako 資料空間內刪除的項目；只有管理員可永久刪除。
- **使用者與權限**：管理員新增使用者並設定分享資料夾讀取／寫入權限。
- **網路狀態**：目前只顯示本機服務狀態及網卡診斷資訊，不提供連線設定。
- **我的電腦**：顯示目前登入者有權存取的 Nanako 資料空間，不會列出 Windows 磁碟、個人資料夾或任意路徑。
- **電腦資訊**：管理員可檢視 Windows／處理器／記憶體／資料磁碟與網路介面狀態。
- **系統設定與操作紀錄**：管理員可查看所有使用者的操作紀錄，選擇 1／3／7／30／90／180／365 日保留期限，並透過輸入確認文字的防呆視窗手動清空全部紀錄。
- **影音格式相容性**：顯示 Electron／Chromium 宣告的格式能力，並允許使用者從 Nanako 資料空間選取影音檔執行播放測試；不開啟外部檔案選擇器、不瀏覽其他磁碟，也不轉換來源檔。

## 操作與回饋

- 成功、失敗、空清單與載入狀態均提供可理解的文字回饋。
- 檔案名稱以文字節點呈現，不將檔名直接插入 HTML。
- 表格標題與輸入欄位提供語意標記；鍵盤可操作主要按鈕與表單。
- UI 會依 `canWrite` 隱藏寫入動作，但伺服器仍獨立執行授權檢查。

## 未來需求（尚未完成）

- **加密空間／檔案上鎖**：上鎖內容必須在 Nanako 資料目錄中以加密資料保存，使 Windows 檔案總管直接開啟時只能取得密文；不能只靠隱藏檔案或 NTFS 權限。需先設計金鑰建立／解鎖／鎖定、記憶體金鑰生命週期、串流加解密、檔名與中繼資料保護、復原／備份，以及相簿和播放器的受控解密流程。目前尚未實作，既有 Nanako 檔案仍是一般檔案。
- **ZIP 壓縮／解壓縮**：一般檔案 ZIP 串流原型已實作，限定 NanakoData 範圍並拒絕路徑跳脫／符號連結／覆寫，採暫存與 CRC 驗證後提交；仍需完成互通性、大檔案與 zip bomb 安全測試。加密空間初版與 ZIP 操作分開，避免明文暫存。
- 上述功能的資料模型、API 草案、威脅邊界與驗收條件見[實作規劃文件](feature-plan-encryption-and-archives.md)及 [ADR-0009](decisions/ADR-0009-encrypted-vault-design.md)、[ADR-0010](decisions/ADR-0010-zip-archive-design.md)。
- 可攜式升級保留資料與復原流程。
- 區域網路連線的啟用開關、網卡/IP 選擇、連接埠設定、連線狀態與複製連線資訊。
- 縮圖快取、轉碼策略、字幕與播放進度記錄。
- API Token 管理、API 文件與整合範例。
- SMB 作為可由使用者自行啟用的後續選項；不是第一版必要條件。

## 用語基準

介面慣用語彙與檢查清單見 [台灣用語指南](terminology.md)。`taiwanizer` 與 `taiwan-md` 僅作語言參考，不會在執行階段載入或自動轉換文字。
