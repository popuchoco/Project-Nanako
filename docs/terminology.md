# 台灣用語指南

介面、文件、錯誤訊息及測試名稱使用繁體中文（台灣），避免直接沿用中國大陸慣用詞。以下是本專案的用語表；新增詞彙時請同步更新。

| 使用 | 避免 | 情境 |
| --- | --- | --- |
| 使用者 | 用戶 | 帳號與權限 |
| 資料夾 | 文件夾 | 檔案管理 |
| 檔案 | 文件 | 一般檔案項目 |
| 資源回收桶 | 回收站 | 刪除與還原 |
| 網路 | 網絡 | 連線狀態 |
| 網路介面卡 | 網卡（面向一般使用者時） | 設定畫面；技術文件可用網卡 |
| 連接埠 | 埠／端口 | 網路設定 |
| 登入 | 登錄 | 帳號操作 |
| 預設 | 默認 | 初始設定 |
| 資訊 | 信息 | 狀態與提示 |
| 軟體 | 軟件 | 一般描述 |
| 影片 | 視頻 | 媒體功能 |
| 相簿 | 相冊 | 圖片功能 |

## 參考方式

- [taiwanizer](https://github.com/Hans-Hanlin/taiwanizer)：作為常見詞彙轉換與詞典授權需分開盤點的參考；本專案未複製程式碼／字典，也未把它加入執行期。
- [taiwan-md](https://github.com/frank890417/taiwan-md)：作為台灣繁體中文語境參考；本專案未複製其內容。

參考專案的授權與目前使用方式詳列於 [THIRD_PARTY.md](../THIRD_PARTY.md)。
