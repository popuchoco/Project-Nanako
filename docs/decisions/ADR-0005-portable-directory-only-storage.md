# ADR-0005：所有使用者資料限於可攜式程式目錄

- 狀態：已採用
- 日期：2026-11-05

## 背景

Project Nanako 是隨選隨用的 Windows 桌面程式。檔案管理、相簿、影音播放與資源回收桶必須有一致且明確的資料邊界；讓使用者選取其他磁碟或外部資料夾會擴大可存取範圍，也會讓可攜式資料位置難以預測。

## 決策

- 可攜式版本將設定、工作階段與使用者資料放在執行檔所在目錄的 `NanakoData`；命令列及開發模式則放在程式目錄的 `NanakoData`。
- 檔案、相簿、播放器、影音相容性測試與資源回收桶都只使用 `NanakoData` 內的資料空間。所有使用者可操作的路徑都由伺服器映射至內部相對路徑。
- 不提供 Windows 磁碟清單、Windows Known Folder、`xdg-user-dirs`、外部目錄選擇器或外部來源掛載功能。
- 匯入檔案是單次明確的複製流程；匯入來源不會出現在 Nanako 的資料樹中，也不能由檔案管理操作修改或刪除。
- 舊版中繼資料若指向資料根目錄外的來源，啟動時會停用該來源；程式不會存取、刪除或移動來源檔案，舊回收桶中繼資料中的實體路徑也不再採用。
- 資料根目錄及其 `files`、`trash` 子目錄不得使用符號連結或 Windows 重新解析點將操作導向範圍外。

## 後果

- 優點：檔案管理、相簿、播放器與回收桶的資料範圍一致；可攜式程式與資料能一併備份或移動。
- 限制：程式不會管理其他磁碟或 Windows 個人資料夾。使用者若要加入檔案，需明確匯入到 Nanako 資料空間；可攜式目錄所在磁碟必須有足夠容量與寫入權限。
