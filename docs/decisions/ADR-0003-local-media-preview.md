# ADR-0003：以本機權限保護媒體預覽與播放

- 狀態：已採用
- 日期：2026-11-04

## 背景

檔案空間需要提供基本相簿與音訊／影片播放，同時維持本機優先、每個分享資料夾各自授權，並避免為第一個媒體版本加入新的執行期套件。

## 決策

- 圖片與媒體一律透過同源 `GET /api/preview` 提供；每次請求重新檢查登入工作階段、分享資料夾讀取權限、路徑範圍與符號連結。
- 僅允許明確列出的圖片／音訊／影片副檔名與 MIME 類型；不把 HTML、SVG 或任意檔案當成可預覽內容。
- 支援單一 HTTP byte range，供 Chromium 原生 `<video>`／`<audio>` 控制項播放與 seek；不實作轉碼、多段 Range 或外掛播放器。
- 相簿目前只瀏覽所選資料夾的圖片；播放器只列出目前資料夾的可播放檔案，資料夾可逐層導覽。
- 不額外複製媒體，也不生成縮圖；瀏覽器載入原圖，縮圖快取列入後續評估。

## 後果

- 優點：使用既有 Electron／Chromium，服務端串流不必把大型影片完整讀入記憶體，權限與一般檔案操作共用。
- 限制：容器支援不代表內部編碼一定可解碼；使用者的瀏覽器／Electron 發行組態會影響格式相容性。
- 驗證：測試 MIME allowlist、讀取權限、合法與不合法 Range；正式 Electron 封裝後仍需用實際影音檔進行播放與 seek 測試。
