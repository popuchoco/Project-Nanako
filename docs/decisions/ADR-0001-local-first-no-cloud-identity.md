# ADR-0001：採本機優先，不依賴雲端身份

- 狀態：已採用
- 日期：2026-11-04

## 背景

產品要能在 Windows 上隨選隨用，並以本機資料管理為核心。需要避免未經使用者要求的雲端帳號、SSO、遠端中繼或資料傳輸。

## 決策

- 帳號、密碼雜湊、權限與工作階段保存在本機 SQLite。
- 本機檔案與資料庫由使用者控制；不呼叫外部登入、遙測或更新服務。
- 不導入 SSO／雲端身份作為登入或 API 整合的必要條件。
- 對外 API 的憑證與權限設計另行決策，必須可撤銷且有明確 scope。

## 後果

- 優點：離線可用、資料流向容易理解，也不需外部帳號才能啟動。
- 代價：密碼重設、跨裝置帳號同步與遠端存取需由產品自行設計，不可假設雲端身份服務會處理。
- 驗證：正式發行前，對完整封裝檔進行網路流量檢查；僅檢查原始碼不足以證明沒有外傳。
