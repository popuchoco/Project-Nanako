# Windows 安裝與資料位置

Project Nanako 提供兩種 Windows x64 發行方式：

| 發行方式 | 建置命令 | 安裝／執行位置 | NanakoData 位置 |
| --- | --- | --- | --- |
| 可攜式版 | `npm run package:win` | 直接執行 `.exe`；需放在目前使用者可寫入的位置 | 可攜式 `.exe` 旁的 `NanakoData\` |
| 使用者安裝版 | `npm run package:win:installer` | NSIS 安裝精靈；單一 Windows 使用者安裝，不要求管理員提升 | Electron `userData` 目錄下的 `NanakoData\` |

安裝精靈的目錄選擇只改變程式安裝位置；資料仍保存在該 Windows 使用者的應用程式資料目錄。解除安裝不會刪除該目錄中的 NanakoData。使用者安裝版不會建立 Windows 服務，也不會修改 Windows SMB Server、防火牆或系統分享。

可攜式版、使用者安裝版與開發版使用不同資料位置，不會在首次啟動、升級或解除安裝時自動搬移資料。若要從可攜式版改用安裝版：

1. 先使用可攜式版的管理功能或 Windows 檔案總管完成備份。
2. 完整退出 Nanako，確認系統匣也已退出，避免 SQLite／檔案仍在使用。
3. 在安裝版第一次啟動前，複製整個可攜式 `NanakoData\` 至目前 Windows 使用者的應用程式資料目錄；不要合併兩個不同版本正在使用的資料夾。若安裝版已建立空白資料目錄，請先完整退出並將它改名保留，再複製資料。
4. 啟動安裝版，於「電腦資訊」確認資料目錄位置及使用者／檔案清單。

回到可攜式版時，請同樣在程式完全退出後複製整個資料目錄。正式的資料搬移／復原精靈仍列入後續規劃；不建議在沒有獨立備份時手動搬移重要資料。

開發者可執行 `npm run test:desktop-smoke` 驗證 Electron 首次設定與重開資料保留；Windows CI 另會建置 NSIS 安裝程式，並在隔離的使用者資料目錄驗證已封裝程式的資料根目錄。
